# Convolute card bundle

This bundle evaluates the isolated RAV Convolute card-definition task. The candidate may edit only `varieties/magic/sets/ravnica_city_of_guilds/src/cards/convolute.rs`.

The task requires the printed `{2}{U}` instant identity and the exact counter-target-spell-unless-controller-pays-`{4}` effect. Two full-game traces exercise both resolution choices: explicit decline and counter, plus explicit payment through four listed land abilities and target resolution. Both continue to a terminal PvP win. The trusted authority owns the target, response, replay, mutation, and task checks. It awards no set credit or Harbor reward.
