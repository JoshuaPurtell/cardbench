# Devouring Light card task

This bundle evaluates RAV Devouring Light in a seeded 60-card PvP game. An opposing Watchwolf must be declared attacking before the defending player casts Devouring Light. Two white creatures pay both white symbols through Convoke, one mana pays the generic symbol, and the exact attacker moves to exile during spell resolution before blockers. The game continues to a terminal result and must replay deterministically.

Gameplay mutants remove Convoke or broaden the target to any creature; both must fail. Passing qualifies only this pilot and awards no credit across the 291-card RAV denominator or Harbor reward.
