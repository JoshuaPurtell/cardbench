# Undercity Shade card task

This bundle evaluates the RAV Undercity Shade candidate in a seeded legal 60-card PvP game. The authority checks the `{4}{B}` cast payment, `{B}` self-pump payment and resolution, a pumped 2/2 attack, rejection of a live nonblack nonartifact Watchwolf block, cleanup expiration to 1/1 base stats, ordered projected events, deterministic replay, and a terminal result.

The card module owns the black 1/1 creature definition, Fear/black-only evasion, and pump ability. The Shade subtype is descriptive task metadata because the current engine card definition has no creature-subtype field. Reference scoring grants zero card credit and zero reward.
