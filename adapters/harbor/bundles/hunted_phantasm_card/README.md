# Hunted Phantasm task bundle

Implement Hunted Phantasm #55 as a candidate-owned RAV card module. The trusted authority validates its exact source and AST before candidate calls, then plays a deterministic two-player 60-card game. It checks the exact blue `{1}{U}{U}` payment, 4/6 unblockable body, opponent-selected ETB, five red 1/1 Goblins created under that opponent's control, live token facts, later-turn combat damage, deterministic replay, semantic mutations, and terminal win. The diagnostic awards zero card credit and zero reward.
