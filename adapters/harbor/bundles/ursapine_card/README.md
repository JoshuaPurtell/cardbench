# Ursapine card task

Implement the RAV Ursapine candidate module. The public contract is in the task's `features.toml`; the isolated authority casts Ursapine in a shuffled two-player game, activates its `{G}` ability targeting a controlled Watchwolf, and follows the temporary +1/+1 effect through combat and cleanup. Candidate output is diagnostic only and carries zero Harbor reward or set credit.
