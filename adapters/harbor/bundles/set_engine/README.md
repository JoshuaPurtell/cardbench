# Set + set-engine Harbor bundle

`cardbench/pokemon/set_engine` grades the expansion overlay as one coherent
submission. A suite selects the expansion and disclosure variant; the
candidate edits only the expansion manifest/card implementation and its
set-specific runtime hooks.

Crystal Guardians is the default public-train reference. A lane is not
authority-ready until fresh sealed heldout fixtures replace the legacy
SetBench fixtures that were previously published.
