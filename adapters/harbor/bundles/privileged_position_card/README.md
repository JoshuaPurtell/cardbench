# Privileged Position single-card PvP bundle

This bundle routes through `varieties/magic/tasks/rav-privileged-position-pvp/harbor.toml`. The trusted full-game authority checks the printed opponent-only target restriction, an opponent Putrefy rejection with no payment or state mutation, and the controller's successful Gather Courage target on the same Watchwolf. It then checks the ordered terminal duel, replay, candidate source guard, and semantic mutations. The task is diagnostic only and grants no card credit or Harbor reward.
