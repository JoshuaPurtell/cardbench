# Blockbuster RAV card task

This bundle implements Blockbuster (RAV #115): a `{3}{R}{R}` red enchantment with a `{1}{R}` activation that sacrifices itself and deals 3 damage to each tapped creature and each player. The full-game authority checks the cost order, targetless resolution, tapped-creature filter, both player damage packets, resulting deaths, deterministic replay, and terminal continuation. The task grants no card credit or reward.
