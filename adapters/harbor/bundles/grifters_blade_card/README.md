# Grifter's Blade CardBench bundle

This bundle runs the isolated RAV #263 task in a bounded, networkless Rust worker. The authority checks Flash timing, the non-targeting as-enters attachment choice before battlefield entry, Equipment attachment, the +1/+1 modifier, Equip `{1}`, a complete deterministic PvP result, and semantic mutations. The task explicitly does not claim support for direct noncast entries. Reports keep pilot rewards and card credit at zero.
