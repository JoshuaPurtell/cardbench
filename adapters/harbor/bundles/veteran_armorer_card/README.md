# Veteran Armorer card task

This bundle evaluates RAV Veteran Armorer in a legal seeded 60-card PvP game. The authority checks its `{1}{W}` cast, a real Watchwolf cast with green and white mana, the Watchwolf's 3/3 base state before the Armorer resolves, and its 3/4 state afterward. It also confirms the Armorer itself remains 2/2, then observes combat receipts and a terminal result with deterministic replay.

The candidate-owned module includes the static binding. A targeted mutation to +0/+0 and a compile-valid +0/+0 stub must both fail the other-creature state gate. Passing qualifies only this pilot; it does not award credit across the 291-card RAV identity denominator or Harbor reward.
