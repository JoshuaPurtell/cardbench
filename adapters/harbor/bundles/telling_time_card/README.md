# Telling Time card bundle

This bundle evaluates the isolated RAV Telling Time card-definition task. The candidate may edit only `varieties/magic/sets/ravnica_city_of_guilds/src/cards/telling_time.rs`.

The task checks the printed `{1}{U}` blue instant identity and the exact private partition of three library cards into hand, top, and bottom. The trusted full-game authority verifies the ordered controller-only snapshot, checks that the opponent's policy view does not expose its decision or candidates, then continues the same shuffled PvP match to a Watchwolf combat win. It also requires deterministic replay and semantic mutation checks. No set credit or Harbor reward is awarded.
