# Keening Banshee card bundle

This bundle exercises the isolated RAV Keening Banshee card task. The candidate may edit only `varieties/magic/sets/ravnica_city_of_guilds/src/cards/keening_banshee.rs`. The offline authority validates the exact printed identity and definition, the mandatory ETB trigger and -2/-2 effect, a complete shuffled duel, deterministic replay, and semantic mutants. This task is diagnostic only: it gives no card credit and no reward.
