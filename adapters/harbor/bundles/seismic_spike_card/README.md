# Seismic Spike RAV card task

This bundle covers RAV Seismic Spike (#141), a red `{2}{R}{R}` sorcery that destroys its target land and then adds two red mana. The reference trace checks exact target provenance, graveyard movement, effect order, mana addition, spending that mana on Viashino Slasher, and a subsequent full-game combat win. The task is diagnostic and awards no RAV set credit or Harbor reward.
