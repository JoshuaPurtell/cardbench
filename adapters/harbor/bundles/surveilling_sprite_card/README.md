# Surveilling Sprite RAV card task

Implement Surveilling Sprite (RAV #67), a `{1}{U}` blue 1/1 creature with Flying and an optional dies trigger that draws its controller a card. In ordinary shuffled two-player games, cast and attack over a live Lurking Informant, then let Char deal lethal damage. Demonstrate both accepting and declining the optional draw and finish each game with a seat-zero win. Reports are diagnostic and grant no RAV coverage or Harbor reward.
