# Bathe in Light card bundle

This bundle evaluates the isolated RAV Bathe in Light card-definition task. The candidate may edit only `varieties/magic/sets/ravnica_city_of_guilds/src/cards/bathe_in_light.rs`.

The authority checks the `{1}{W}` white instant, chosen color, creature target, Radiance recipients across both controllers, nonmatching and colorless exclusions, protection-based target legality, and a full-game terminal trace. The task awards no set credit or Harbor reward.
