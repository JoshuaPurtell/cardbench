# Quickchange card task

This bundle evaluates RAV Quickchange in a seeded full-game PvP duel. The authority casts the blue `{1}{U}` Instant on a Watchwolf, chooses Red, verifies the target becomes only red and returns to green-white at end of turn, and checks the one-card draw. The Watchwolf attacks after the effect expires and the game continues to a terminal result.

The authority replays deterministically and rejects mutations that remove color replacement, remove the draw, or change the printed cost. Passing qualifies only this pilot and awards no credit across the RAV 291-name/306-printing denominator or Harbor reward.
