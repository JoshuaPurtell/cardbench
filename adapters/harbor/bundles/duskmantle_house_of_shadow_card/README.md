# Duskmantle, House of Shadow card task

This bundle asks for the RAV #277 card definition and its `{T}: target player mills one card` activation in the candidate-owned module. The private reference authority checks the activation's target and exact library-to-graveyard transition in a deterministic full PvP game, plus semantic mutations. The task is diagnostic and does not award card credit.

Read the task README and `features.toml` in the trusted handoff before editing. The public candidate workspace exposes only the declared Rust module.
