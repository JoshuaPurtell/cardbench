# Dizzy Spell card bundle

This bundle exercises the isolated RAV Dizzy Spell task. The candidate may edit only `varieties/magic/sets/ravnica_city_of_guilds/src/cards/dizzy_spell.rs`. The local offline authority checks its exact printed identity, the Transmute search and same-object cast, an attacking Watchwolf's -3/-0 effect and zero combat damage, a complete shuffled duel, deterministic replay, and semantic mutants. This is diagnostic only: it grants no card credit or reward.
