# Rally the Righteous RAV card task

Implement the candidate-owned definition for Rally the Righteous (RAV #222), a `{1}{R}{W}` instant: “Radiance — Untap all creatures that share a color with target creature. They get +2/+0 until end of turn.” The reference authority runs an ordinary shuffled 60-card two-player game and casts the spell during the priority window after declaring two Boros Swiftblades as attackers. It pays Red, White, and Red, chooses one attacking Swiftblade on the live stack, and verifies that Radiance untaps both same-color attackers and makes each a 3/2 before blockers.

The defending player blocks the targeted Swiftblade with a mono-green Golgari Brownscale. First strike lets the targeted 3-power creature kill its 2/3 blocker before normal combat damage; the other Swiftblade deals 3 damage to the defending player in both combat damage steps, ending the game in seat zero’s win. The trace checks ordered mana payment, cast, both Radiance continuous effects, untapping, resolution, blocker assignment, both damage steps, state-based action, and graveyard movement. Reference mutations to the +2 power bonus, same-color/untap behavior, and red-white cost must each be detected. Diagnostic reports credit no RAV coverage or Harbor reward.
