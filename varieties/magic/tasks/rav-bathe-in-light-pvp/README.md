# Bathe in Light RAV card task

Implement the candidate-owned module for RAV #2, Bathe in Light. It is a white `{1}{W}` instant with a chosen color and a creature target. Its Radiance effect protects that target and every other creature that shares a color with it until end of turn.

The trusted authority runs a shuffled, legal 60-card PvP match. It checks the cast payment, target and color choices, the exact Radiance recipient set across both controllers, and the exclusion of colorless and nonmatching creatures. The same trace checks protection-based target rejection and a legal nonmatching-color target, then continues to a seat-zero Watchwolf combat win with deterministic replay and semantic mutations. The task awards no set credit or Harbor reward.
