# Golgari Thug source note

This task follows [`RAV_PVP_SOURCE_CONTRACT.md`](../rav-set-pvp/RAV_PVP_SOURCE_CONTRACT.md): the original Ravnica: City of Guilds printing controls card identity and tested mechanics; current Oracle is consulted only to interpret rules questions. The official Wizards card-gallery record is [RAV #87 Golgari Thug](https://mtg-jp.com/products/card-gallery/0000057/88994/). It identifies a 1/1 Creature — Human Warrior with Dredge 4 and a death trigger targeting a creature card in its controller's graveyard and putting it on top of its owner's library. The set catalog records its printed `{1}{B}` cost and black color.

The RAV printing uses the older “put into a graveyard from play” event wording. Current Oracle uses “dies,” which represents that same battlefield-to-graveyard event, and otherwise preserves the target zone, creature-card restriction, and library-top destination. The authority uses the engine's `TriggerCondition::Dies` interpretation while retaining the printed target and effect. It tests Dredge 4 separately by replacing an actual draw, milling exactly four cards in library order, and returning the same Thug object to hand before recasting it.

The printed Human Warrior subtype is retained as public identity but not asserted: `CardDefinition` currently represents Creature and has no creature-subtype field. The task retains public identity facts and CardBench-authored semantic summaries only; it stores no scans, card images, flavor text, or upstream rules-text corpus.
